# Victoria 3 Modding Journey

A living record of my self-directed learning journey into game modding, 
coding, and developer tooling — started from zero coding experience in 2026.

## What's in this repo

**Mods** — Victoria 3 mods I've built while learning, from simple country 
renaming to custom nations. Each mod folder contains the actual game files.

**Tools** — Small apps and utilities I've built along the way, like a 
progress tracking app built with HTML, CSS and JavaScript.

**Notes** — Lessons learned, bugs solved, and things I want to remember.

## The learning path

Working through a structured curriculum that covers:
- Localization and text modding
- Tweaking game numbers and values
- History files and starting conditions
- Creating custom events and decisions
- Building entirely new content
- Creating a custom country from scratch

## Why this exists

I started this project to build marketable technical skills while doing 
something genuinely fun. Modding games turns out to be a great way to 
learn how real software systems are structured.
